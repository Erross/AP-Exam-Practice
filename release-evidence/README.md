# Release Evidence Archive

Files in this directory are **point-in-time release records**, not live product specifications.

Each file preserves the sources, candidate commits, bank measurements, draw/retake simulations, clean-room findings, and CI evidence used to release a course at that time. Those historical measurements should not be silently rewritten later just because the course, repository test count, or College Board exam cycle changes.

For current product state, use:

1. [`../README.md`](../README.md) for released-course scope and user-facing limitations;
2. the effective course metadata loaded by `../index.html` for current configured exam behavior;
3. [`../CONTENT_STANDARDS.md`](../CONTENT_STANDARDS.md) and [`../SUBJECT_RELEASE_CHECKLIST.md`](../SUBJECT_RELEASE_CHECKLIST.md) for the current release standard.

When a released course is materially revised, add new release evidence for the new candidate rather than retroactively altering the old snapshot.
